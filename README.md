# Náhled nového webu – Plicní centrum Spořilov

Statický náhled připravovaného webu [plicnisporilov.cz](https://plicnisporilov.cz) pro připomínky týmu a jako předloha pro webmastera. **Nejde o ostrý web.**

Náhled běží na GitHub Pages: <https://plicni-sporilov.github.io/web-nahled/>

Stránky mají `noindex` a `robots.txt` zakazuje procházení, aby se náhled nedostal do vyhledávačů a nesoupeřil s ostrým webem.

## Obsah

| Soubor | Stránka |
|---|---|
| `index.html` | Úvodní stránka |
| `plicni-ambulance.html` | Plicní ambulance |
| `centrum-spankove-mediciny.html` | Centrum spánkové medicíny |
| `funkcni-vysetreni-plic.html` | Funkční vyšetření plic |
| `screening-rakoviny-plic.html` | Screening karcinomu plic |
| `lekar-*.html` | Profily lékařů |
| `img/` | Fotky a logo |

Čisté HTML a CSS, jediný skript je galerie fotek na úvodní stránce. Nic se nebuildí, úprava souboru a push stačí.
